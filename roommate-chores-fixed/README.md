# 🏠 House Rules

A fun roommate chore tracker built with React and Vite.

## Features

- Individual roommate logins
- Weekly automatic chore rotation
- Chore completion tracking
- Everyone's assignments displayed
- Light and dark mode
- Responsive design
- Trash restriction for King
- Six rotating chores

## Chores

- 🍽️ Dishes
- 🗑️ Trash
- 🛁 Bathroom
- 🧹 Vacuum
- 🧺 Laundry
- 🧽 Kitchen

## Running locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Important security note

This starter version contains the login credentials in `src/data.js` so it can run immediately.

Do not use this authentication method for a public production application. Before making the repository public, move authentication to Supabase Auth or another secure authentication provider.
